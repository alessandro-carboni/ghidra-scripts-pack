## Answers to the ten research questions

1. **More informative graph similarity?** A controlled equal-role co-location collision passes through the actual frozen canonical/fingerprint commands with identical three-view semantic digest and baseline similarity 1.0. The new co-observation view distinguishes it and the graph-first mean is below 1.0. This is a narrow ablation, not a population claim.
2. **Original generic-topology collisions reduced?** No. The historical audit rerun finds the same 39 identical negative descriptor multisets among 67 negatives; 32 are topology-only. None is resolved by the new view. Per-pair feature counts/families, anchor context, typed observations, excluded canonical observations, uncertainty and source links are in HISTORICAL_COLLISIONS.json. Unobserved computation cannot be reconstructed by inventing graph facts.
3. **Compiler/optimization robustness?** Not established. Eleven of eighteen required fresh builds have valid recorded hashes/receipts. Compilation of the twelfth completed but Bitdefender quarantined it before its hash could be read. The required matrix is incomplete; the runner rejects it rather than evaluating a convenient subset.
4. **Transformed-region retrieval?** Seed/context contract tests cover wrapper, thunk, splitting, inlined-shaped graphs and irrelevant surrounding nodes. These are structural synthetic controls, not proof of compiled transformation robustness. The real development preflight recovers the expected subject, foil and helper seed for the equivalent wrapper. Full transformed retrieval remains unmeasured.
5. **Automatic seed selection coverage?** On one GCC O0 development build, 5 total seeds were detected; all 3 defined functional regions had eligible seeds, including the equivalent region whose observable call is in effect_helper. The no_seed symbol was not recovered by Ghidra, so its real-binary detector coverage is unknown, not a false negative or successful exclusion. A separate synthetic source with no supported observations produces an explicit empty index. This is not heldout coverage.
6. **Complementary P-code evidence?** Source/context/binary-bound optional analysis works: the same real development subgraph has graph self-similarity 1.0 and operational self-similarity 1.0. No cross-case complementarity claim follows. A low operational score is not a verified contradiction.
7. **Refinement reduces false positives without recall loss?** Not measured yet. E uses graph top5 and reorders only slots with available operational evidence; missing evidence keeps graph rank. Tests show a true reference outside the admitted set cannot be recovered. The runner records candidate Recall@1/3/5 and excluded positives separately from final retrieval.
8. **Graph/operational redundancy?** Pending new A–E results. Prior operational layer studies do not answer this graph-first question. No new weights were selected from previous score outcomes.
9. **Interpretable/reproducible?** Targeted tests validate stable reconstruction, relocation/permutation invariance of descriptors, strict provenance rejection, explicit budgets and score explanations. Generic topology is qualified through support, not relabeled as behavioral confidence. Scientific reproducibility of the complete real matrix remains pending.
10. **Generalization?** Not established. Even the intended completed dataset is internally authored, only six source families and correlated compiler builds, with source-level contracts rather than executed binary or formal whole-function proofs. External blinded replication and realistic malware retrieval remain future validation.

## Preregistered experiment

Six new unsigned-byte-buffer source families, two per discovery/validation/heldout partition. Region semantics cover a readable buffer with length 0–16, return values and the common allocation/free observation sequence under stable OS availability; pointer identities and timing are excluded. Equivalence arguments use commutative sum/xor of equal per-index terms, with an equivalent wrapper/helper. Foils toggle bit0. The manifest records 520 oracle inputs per family, source formula output digests, source hashes and 12 cross-family negative witnesses. These are contract examples and algebraic arguments, not 3,120 executions or a compiled-equivalence proof.

A: unchanged frozen structural mean. B: frozen graph views plus justified co-observation view. C: unchanged operational-only. D: preregistered half-mean, with explicit graph fallback when operational evidence is unavailable. E: graph top5 available-slot operational refinement; graph numeric score stays B. Candidate references are independently judged study regions, not all unknown runtime/CRT seeds; every detected seed is still preserved in its index. Claims from this controlled gallery must not be extended to unjudged binaries.

Primary metrics are B heldout MRR/Recall@K and candidate/eligibility coverage. Secondary metrics include ROC and raw partial AUC on [0,0.05], tie bounds, margins, same-family versus cross-family negatives, and discovery-only thresholds. Both directed retrieval rows are recorded for each unordered pair; they are not independent samples. No heldout results exist, no method was selected post-hoc, and no default was promoted.

The original registration is retained as protocol.json. Three pre-evaluation technical amendments are retained and hash-linked: optional unrecovered no_seed symbol and binary binding; null-evidence admission/mean handling plus amendment provenance; complete 18-build matrix/source-split validation. Only development self-comparisons and synthetic controls were inspected before these amendments, never cross-case scores from the new corpus. None changes available-score formulas, labels, partitions, weights or candidate policy.
